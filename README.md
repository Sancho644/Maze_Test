# First Person Maze Prototype

Тестовое задание на позицию **Unity Developer**.

Небольшой прототип игры от первого лица, в котором игрок исследует лабиринт, собирает бриллианты, избегает врагов и пытается добраться до выхода.

---

# Unity Version

- Unity 6
- C#
- Zenject (Extenject)

---

# Управление

| Действие | Клавиша |
|----------|----------|
| Движение | **W / A / S / D** |
| Осмотр | **Mouse** |
| Бег | **Left Shift** |
| Перезапуск уровня | Кнопка **Restart** после победы/поражения |

---

# Игровой цикл

1. Игрок появляется в лабиринте.
2. В случайных точках появляются бриллианты.
3. Игрок собирает все бриллианты.
4. После сбора всех бриллиантов становится доступен выход.
5. Игрок добирается до выхода и побеждает.

Во время игры по лабиринту перемещаются враги.

Если враг касается игрока — игра завершается поражением.

---

# Архитектура проекта

Проект построен с использованием следующих подходов:

- Dependency Injection (**Zenject**)
- Event Driven Architecture (**SignalBus**)
- FSM (Finite State Machine) для поведения врагов
- ScriptableObject для игровых настроек
- Разделение ответственности (Single Responsibility Principle)

---

# Структура игровых систем

## Player

### Player

Маркер-компонент игрока.

Используется другими системами через Dependency Injection.

---

### PlayerMovement

Отвечает за:

- перемещение игрока;
- обработку ввода;
- бег;
- работу с CharacterController.

---

### PlayerLook

Отвечает за:

- вращение камеры;
- ограничение вертикального угла обзора.

---

### PlayerConfig (ScriptableObject)

Хранит игровые параметры игрока:

- скорость ходьбы;
- скорость бега;
- чувствительность мыши;
- минимальный и максимальный угол обзора.

---

## Diamonds

### Diamond

Отвечает за:

- обнаружение игрока;
- отправку события сбора;
- удаление объекта после подбора.

---

### DiamondSpawner

Создает бриллианты в случайных заранее подготовленных точках спавна.

---

### DiamondManager

Отвечает за:

- подсчет количества бриллиантов;
- обновление UI;
- определение момента, когда собраны все бриллианты.

---

## Enemies

Поведение врагов реализовано в виде конечного автомата (FSM).

### EnemyBrain

Главный контроллер поведения врага.

Переключает состояния FSM.

---

### PatrolState

Враг патрулирует между заданными точками.

---

### ChaseState

После обнаружения игрока начинает его преследование.

Если игрок покидает область обнаружения — враг возвращается к патрулированию.

---

### EnemyVision

Отвечает за обнаружение игрока.

Проверяет:

- радиус обнаружения;
- угол обзора;
- наличие препятствий между игроком и врагом.

Для удобства настройки реализованы **Gizmos**, отображающие радиус и сектор обзора в редакторе.

---

### EnemyMovement

Отвечает за перемещение врага через NavMeshAgent.

---

### EnemyAttack

Определяет контакт с игроком и инициирует поражение.

---

### EnemyConfig (ScriptableObject)

Содержит параметры врага:

- скорость;
- радиус обзора;
- угол обзора;
- дистанцию обнаружения.

---

## Exit

### ExitController

После получения события о сборе всех бриллиантов активирует возможность завершения уровня.

При входе игрока в область выхода инициирует победу.

---

## UI

### GameUI

Отображает:

- счетчик бриллиантов;
- экран победы;
- экран поражения.

---

### RestartButton

Перезагружает текущую сцену.

---

### CursorController

Управляет состоянием курсора.

Во время игры курсор скрыт и заблокирован.

После победы или поражения курсор становится доступен для взаимодействия с UI.

---

# Игровая логика

## Победа

Последовательность работы системы:

```
Diamond
        ↓
DiamondCollectedSignal
        ↓
DiamondManager
        ↓
AllDiamondsCollectedSignal
        ↓
ExitController
        ↓
PlayerReachedExitSignal
        ↓
GameManager
        ↓
GameState = Win
        ↓
GameUI
```

---

## Поражение

Последовательность работы системы:

```
EnemyAttack
        ↓
PlayerDiedSignal
        ↓
GameManager
        ↓
GameState = Lose
        ↓
GameUI
```

# Где находится логика сбора бриллиантов

| Класс | Ответственность |
|--------|-----------------|
| Diamond | Подбор бриллианта игроком |
| DiamondSpawner | Создание бриллиантов |
| DiamondManager | Подсчет прогресса и открытие выхода |

---

# Где находится логика врагов

| Класс | Ответственность |
|--------|-----------------|
| EnemyBrain | Управление FSM |
| PatrolState | Патрулирование |
| ChaseState | Преследование |
| EnemyVision | Обнаружение игрока |
| EnemyMovement | Перемещение |
| EnemyAttack | Поражение игрока |

---

# Использованные архитектурные решения

- **Zenject** — Dependency Injection.
- **SignalBus** — обмен событиями между системами.
- **FSM** — управление поведением врагов.
- **ScriptableObject** — хранение игровых настроек.
- **CharacterController** — движение игрока.
- **NavMeshAgent** — навигация врагов.

---

# Особенности проекта

- Полностью разделена ответственность между игровыми системами.
- Игровые системы взаимодействуют через события без жестких зависимостей.
- Все основные параметры вынесены в ScriptableObject.
- Поведение врагов реализовано через конечный автомат.
- Настройка области обнаружения врагов производится с помощью Gizmos.
- Проект готов к расширению без существенных изменений существующей архитектуры.
